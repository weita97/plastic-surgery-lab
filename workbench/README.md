# 每日学习工作台

面向整形外科 / 干细胞与创面修复方向博士生的单文件每日学习工作台。

## 使用

直接打开 <https://USERNAME.github.io/REPO/> 即可，手机、电脑同一网址。
也可以下载 `index.html` 双击本地打开，功能完全一致。

## 功能

- 🌱 每日成长语录：30 条 / 6 分类，每日轮换 3 条，支持朗读与复制
- 🔤 英语：六级词汇（每日 50 词 + 次日复习）、文献阅读、每日听力、雅思、托福、常用短语 100+
- 🔬 科研进展：顶刊速递每日实时抓取 PubMed 近三年 CNS 及子刊 / 一区 IF≥10 文献，中英对照，支持收藏
- 📅 时间安排表：月历，可标记实验安排 / 出行安排 / 重要提醒
- 💰 账本：支付宝 / 微信分账，6 类消费统计
- 🔥 国自然项目查询、💡 AI 科研工具、💡 科研数据库
- 💡 选题灵感：10 个方向每日轮换 4 个，可收藏
- 📝 每日复盘

## 说明

- 纯静态单文件，无后端、无依赖、无构建。
- 所有数据保存在**本机浏览器 localStorage**，不上传服务器；换设备或换网址数据不互通，可用侧栏「⬇ 导出备份」迁移。
- 顶刊速递的实时抓取与翻译需要联网，断网时自动回退到内置的 199 篇文献库。
